# AGENTS.md

## Purpose

This workspace is a durable knowledge and project record. Keep information findable without turning temporary thoughts into canonical truth.

## Information states

Treat inbox/scratch material as provisional. A meeting note records what was discussed; it does not become a project decision until the workspace's decision or status record says so.

Prefer linking to an existing canonical note over creating a near-duplicate.

## Changes and lifecycle

Preserve useful history. When information is obsolete, mark or archive it according to the workspace's existing convention and leave enough context to find its replacement.

When a task materially changes project state, update the canonical project/status record if one exists.

Do not reorganize large parts of the workspace merely to make the current task cleaner. Make the smallest structural change that improves the durable record.

## Uncertainty

Mark facts that are unverified or disputed. Do not fill missing project, person, or decision details from plausible guesses.

## Completion

A workspace-maintenance task is complete when the requested artifact is correct, its canonical status/index is synchronized when applicable, and no newly created durable information is stranded or duplicated.
