# Specification review

Evaluate whether the specification is a usable durable contract for the work it is meant to guide.

Check that the requested behavior and scope are unambiguous enough to act on, material decisions are explicit, non-goals or boundaries are clear where omission would create scope risk, and acceptance conditions can distinguish a conforming result from a non-conforming one.

Flag hidden design decisions that an implementer would otherwise be forced to invent, contradictions between requirements, and acceptance criteria that merely restate implementation details instead of observable outcomes.

Do not require exhaustive prose. Missing detail is a finding only when its absence can materially change implementation, verification, or stakeholder expectations.
